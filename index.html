LineBot Client01 Backup

This website provides public information about LineBot Client01 Backup, a privately administered database backup utility.

Purpose

The utility is intended to help an authorized administrator maintain backup copies of application data associated with a LineBot service.

Google Drive Integration

Google Drive access is used to upload, manage, and retrieve backup files within an authorized Google account. Access requires Google OAuth authorization.

Access and Security

This utility is intended for administrator use only. It is not a public-facing customer application. Google OAuth credentials and database backup files are not stored on this website.

Privacy

Information about Google Drive permissions and data handling is provided in our Privacy Policy.
